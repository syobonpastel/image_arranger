# Image Arranger

画像をInstagram / X(Twitter)用のサイズに整形し、余白に文字を入れられるWebアプリ。

## 機能

- 貼り付け（⌘V / Ctrl+V）・ドラッグ＆ドロップ・ファイル選択で画像を読み込み（複数可）
- 複数の画像をタブで切り替えて編集（ぼかし・配置はタブごと、文字の設定は全タブ共通）
- Instagram（4:5 / 1:1 / 9:16 / 1.91:1）、X（16:9 / 4:5 / 1:1）のサイズに余白付きで整形（位置・大きさはサイズごとに記憶）
- 余白に文字入れ。上下の余白なら横書き、左右の余白なら縦書き（または横書き）で自動配置
- ぼかしペン（ぼかし / モザイク、消しゴム、元に戻す）
- 文字などの設定はCookieに自動保存
- 複数サイズ・全タブをまとめてZIPでダウンロード、クリップボードにコピー、共有

## 使い方

公開版: https://syobonpastel.github.io/image_arranger/

ローカルで動かす場合（ビルド不要の静的サイト）:

```bash
python3 -m http.server 8000
```

http://localhost:8000 を開く。（`file://` で直接開くとブラウザによってはCookieが保存されないため、ローカルサーバー経由を推奨）
